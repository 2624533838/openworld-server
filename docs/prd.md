# 产品设计文档（PRD）

## 一句话定位

一款小体量、可联机游玩的 **2D 开放世界 RPG 演示产品**——一个，用来把「开放世界 + 多玩家实时同步」这件事在可完成的尺度下做出来、跑起来、讲清楚。

## 产品目标

这不是一款商业游戏，而是一款**验证型作品**，双目标：

1. **技术验证**：证明一个人能实现开放世界 RPG 服务端的核心能力（AOI 视野、状态同步、数据持久化）。
2. **作品展示**：作为游戏服务端的作品集项目，。

## 目标用户与场景

- **使用者**：想体验「和真人一起在开放世界里走动」的玩家（测评/演示/）。
- **场景**：玩家打开客户端 → 登录 → 进入世界 → 自由移动 → 与附近其他玩家相遇、互动 → 退出，下次登录数据仍在。

## 核心玩法循环（MVP 版）

```
登录 → 出生 → 自由移动
               ↓
    与附近玩家相遇（实时看见彼此移动）
               ↓
        走远 → 视野内消失
               ↓
        退出（MVP 暂不落盘）
```

这条循环虽然简单，但正是「开放世界」区别于「房间制对战游戏」的核心体验：**一个共享的、持续存在的世界**，玩家在其中自由移动并实时相遇。

## 主要功能模块

| 模块 | 说明 |
|------|------|
| 账号与登录 | 客户端连接服务器，登录后分配唯一玩家 id 与出生点 |
| 开放世界地图 | 一张 2D 大地图，按格子分块（为 AOI 与后续 zone 打基础） |
| 实时移动同步 | 自由移动，服务器权威校验，同屏玩家实时可见 |
| 视野系统（AOI） | 九宫格：只同步附近玩家，走近加载、走远消失 |
| 多玩家交互 | MVP 先做到「看得见彼此」，聊天/交易/组队留后续 |
| 数据持久化 | 角色数据存档（MVP 内存态，后续接 Redis/MySQL 落盘） |

## MVP 范围

**保留（最小可演示闭环）**：登录、移动（服务器权威）、九宫格 AOI 视野、多玩家同屏同步。

**暂缓（后续迭代）**：

- Redis/MySQL 落盘 → MVP 先内存态
- 网关/逻辑服拆分 → MVP 先单进程
- 心跳/断线重连的完整处理
- 压测工具（后续做）

## 后续演进方向（非目标）

- 更丰富的世界内容：多个 zone、怪物/NPC、任务
- 社交系统：聊天、组队、好友
- 战斗系统：技能、属性、掉落
- 分布式扩容：多逻辑服分线

> 明确不做：商业级画面与内容量、大规模分布式、移动端。目标是「小而完整」，不是「大而全」。
